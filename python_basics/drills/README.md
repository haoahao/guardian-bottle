## 做完怎麼上傳（commit）

做完 D01～D05 上傳一次，做完 D06～D10 再上傳一次，這樣 commit 歷史會留下兩筆紀錄。

1. 到 GitHub 的 repo → `groups` → 自己組的資料夾（例如 `g3`）
2. **Add file** → **Upload files**
3. 把寫好的 `d01_card.py`～`d05_list.py` 拖進去
4. 下方 commit 訊息寫：`第3組 Python 練習 D01-D05（王小明、李小華）`
5. 按 **Commit changes**

第二次上傳同名檔案會直接覆蓋，GitHub 會記下改了哪幾行。點檔案上方的 **History** 就看得到。
