# 各組成果資料夾

每組一個資料夾（g1～g9），只上傳到自己組的資料夾。

## 第一週要上傳的四樣東西

1. `chart.png`：STEP 1 時 Thonny 繪圖器（檢視 → 繪圖器）的動作圖表截圖
2. `main.py`：改成你們組門檻的版本
3. `觀察紀錄.md`：打開資料夾裡的範本，按鉛筆圖示（Edit）直接填
4. 接線照片一張（jpg 或 png）

## 怎麼上傳

進自己的資料夾 → **Add file** → **Upload files** → 把檔案拖進來 → 下方 commit 訊息寫「第 N 組 第一週：TH_IMPACT=○、TH_TILT=○」→ **Commit changes**。
